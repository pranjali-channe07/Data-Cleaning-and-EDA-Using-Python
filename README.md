# Data Cleaning and Exploratory Data Analysis Using Python

## Project Overview
This project focuses on data cleaning, preprocessing, and exploratory data analysis using Python. It includes two tasks: cleaning the Iris dataset and performing EDA on a Customer Churn dataset.

## Task 1: Data Cleaning and Processing

**Dataset:** Iris Dataset

### Activities:
- Loaded the dataset using Pandas.
- Explored dataset structure and dimensions.
- Checked missing values.
- Identified and removed duplicate records.
- Generated descriptive statistical summaries.
- Exported the cleaned dataset as a CSV file.

## Task 2: Exploratory Data Analysis (EDA)

**Dataset:** Customer Churn Dataset

### Activities:
- Loaded and explored the customer churn dataset.
- Generated statistical summaries.
- Checked missing values.
- Visualized customer churn distribution.
- Created histograms and scatter plots.
- Generated a correlation heatmap.
- Analyzed average daily minutes and customer service calls.
